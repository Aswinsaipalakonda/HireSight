# Data Directory

This directory holds all HireSight datasets.

## Folder layout

- `raw/` — CSV files generated by `scripts/generate_dataset.py`. These files are **immutable**; never edit them manually. Regenerate them from the script if needed.
- `processed/` — cleaned outputs produced by the cleaning scripts/notebook (Phase 2). All analysis, SQL loading, Excel, and Power BI work uses processed files.

## Dataset overview

| Item | Value |
|---|---|
| Random seed | 42 |
| Applications | ~8,000 |
| Unique candidates | ~3,500 |
| Jobs | 45 |
| Period | 2026-01-01 to 2026-12-31 (synthetic) |
| Currency | INR (illustrative) |

## Provenance

All data is **synthetic** and generated with a fixed random seed for full reproducibility.
There are no real candidates, names, emails, phone numbers, or addresses. City labels are
broad fictional/illustrative Indian city labels.

## Intentional data-quality issues

The raw dataset deliberately contains a controlled number of realistic data-quality issues
for cleaning demonstrations (see `raw/generation_metadata.json` for exact counts):

- Missing `highest_education` / `experience_years` values in `candidates`
- Inconsistent casing / stray whitespace in some categorical fields
- A few invalid date orders in `application_stage_history`
- A few missing `source_id` values in `applications`
- A few out-of-range AI screening scores in `screening_results`
- A small number of near-duplicate candidate profiles (documented, not duplicate application IDs)

These are resolved or quarantined in `processed/` during cleaning, with an audit log.
